# Test

Языковая пара: **EN → RU**

Этот репозиторий создан в [GiCat](https://github.com/) — Git-ориентированной системе автоматизированного перевода.

## Структура

- `files/*.xlf` — двуязычные документы проекта (XLIFF 1.2);
- `files/sources/` — исходные файлы;
- `glossary.tsv` — терминология проекта;
- `inbox/` — входящие файлы от клиентов;
- `.gicat/project.json` — настройки проекта и критерии качества.

Каждый коммит фиксирует изменение текста. Переводы можно редактировать в GiCat или в любом Git-клиенте — GiCat подхватит изменения при синхронизации.
